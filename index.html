Questions

The honest answers.

Is it safe?

The Safe tier uses settings Windows already lets you change. Optional and Risky tweaks are labelled as such, explain their cost, and Risky ones ask before they run. possible tries to create a Windows restore point first and keeps a snapshot of each change so it can be undone.

Will it make my games faster?

Often it helps a little, sometimes a lot, sometimes not at all. It depends on what your PC was doing in the background and on your hardware. We do not publish FPS numbers because they would not be true for your machine.

Why does Windows show a warning when I open the installer?

possible is new and the installer is not yet signed with a paid code-signing certificate, so Windows SmartScreen may say it does not recognise the app. Choose More info, then Run anyway. Because the app edits system settings, it asks for administrator rights when it starts.

Can I use one licence on several PCs?

A licence key can be activated on a limited number of PCs. The limit is shown when you buy. If you change computer, write to support and we will sort it out.

Does it need internet?

It checks your licence when it starts. If you are offline, it keeps working for up to seven days after the last successful check.

What if something goes wrong?

Undo the tweak in the app. If you need more, use the Windows restore point that possible created before its first change. And write to us: we read every message.

Which games does it support?

The tweaks, Network and Debloat work for any game. The Fortnite screen is specific to Fortnite.
